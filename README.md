# AI-Based VLSI Power Analysis Dashboard

## Overview

This project is an AI-powered VLSI power estimation and analysis system developed using Python, Flask, Machine Learning, HTML, CSS, and JavaScript. The system predicts power consumption in VLSI circuits based on circuit parameters and provides engineering-based analysis with visualization dashboards.

The project combines machine learning prediction with analytical VLSI power equations to improve understanding of circuit power behavior.

---

## Features

* AI-based power prediction
* Interactive dashboard interface
* Engineering-style power odometer gauge
* Power classification (Low / Moderate / High)
* Interactive voltage vs power analysis graph
* Dynamic recommendations for optimization
* User login and authentication system
* Modern industry-style UI dashboard
